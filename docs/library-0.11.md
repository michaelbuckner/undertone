**Undertone / preset and session library / v0.11.0**

Open **Library** beside Performance and Sound. Search by name/style, then use Show to choose All items, Factory presets, Saved sessions, Kept moments or Recent files. Selecting a row displays its key, tempo, phrase length, composition, engine and melody voice. **Load selected** (or Return on the selected list row) loads it stopped. Browsing leaves the playing session alone.

Factory entries are the twelve existing Starting character presets. They retain your A/B scene bank, just as the quick Starting character selector does. Pad tones remain in Sound. Saved sessions restore the complete stored session, including their scene bank.

**Save and Save variation.** The header displays the current name and one of Unsaved, Saved, Edited, Updating or Queued edit. Save asks for a filename when the session has none; subsequently it updates that file and retains the previous copy as `.undertone.bak`. Library > Save variation always opens a save dialog with a new suggested filename, so you can keep the original. It snapshots the current phrase and settings when the dialog opens. If music evolves while you name the file, the live session can still show Edited after saving.

The existing save contract remains: manually queued harmonic changes are not saved until applied. The header says Queued edit rather than Saved while such changes remain. Play / restart applies them immediately on internal clock; external-clock edits follow their existing musical boundary. For Save copy & load, apply queued edits first so the copy contains the work you intend to keep.

**Replacing a session.** Loading a factory preset, a session file, or recovery with edits present offers Save copy & load, Discard & load, and Cancel. Cancel leaves the current session intact. Canceling the save dialog or encountering a write failure also leaves it intact. Save copy & load continues only after a successful save. This guard also covers the quick Starting character selector and Open.

Edited compares the current musical state against the last loaded/saved state. Sound changes, realized chord/motif changes and scene edits count. The advancing tone-modulation phase and external-clock tempo jitter do not. Returning settings to their baseline clears Edited. This is an indicator, not a new undo system; existing recovery still runs and the app still opens with Quiet room on a new launch.

**Files and folders.** New variations default to the `Sessions` folder inside Undertone's application-data directory (`%APPDATA%/Undertone/Sessions` on Windows). Save elsewhere if preferred. Open adds a successful file to Recent; Add folder includes `.undertone` files directly inside that folder, without copying or moving them. Refresh rescans the catalogue. The library remembers up to 20 recent files and 12 added folders in `library.json` beside the recovery file. Kept moments uses the existing `Documents/Moments` location. `UNDERTONE_DATA_DIR` isolates all these locations for development tests.

Duplicate names are kept as separate entries when their paths differ; the detail pane shows the full path and its tooltip. Missing recent files remain listed; invalid or missing selections show an error with Load disabled. Opening an invalid file does not modify the current session. Unrelated files and `.bak` backups are not listed.
