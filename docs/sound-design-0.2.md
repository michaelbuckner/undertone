**Undertone 0.2 — audible evolution and independent tones**

This revision responds to Mike's first listening pass: retain the ambient and neo-soul starting sounds, improve funk articulation, and move the industrial direction toward the slower, darker ambient side of later Nine Inch Nails. These are starting points for another listening pass, not recreations of particular recordings.

**Evolve.** Turn Evolve on and choose Chords + tone, Chords only, or Tone only. The interval is independent of bars per chord: 1, 2, 4 or 8 bars are useful starting choices; 16 and 32 are also available for slow work and legacy imports. With Variation above zero, each harmonic evolution changes at least one unlocked chord to a different scale degree. It favors the chord that will sound at the boundary, then uses Variation to determine additional replacements. Locks retain exact notes. If the sounding chord is locked, a later unlocked chord changes instead, so the audible harmonic change may arrive later.

Tone evolves continuously through a repeatable smooth cycle of brightness, texture and space. Variation controls its depth. It does not alter level, key, bass cut, or the note floor. All chord locks can stay enabled while tone moves. In Original Warm, the texture parameter is inactive; brightness and space still morph. The chord strip shows the countdown, harmonic evolution count and current tone values. The knobs show the underlying patch values, not moving modulation values. Variation zero disables both targets; switching Evolve off returns to the base patch with smoothing. Playback Stop freezes the tone phase and releases notes; Panic clears tails. The tone cycle length uses the tempo estimate when following external clock, while chord replacements use counted MIDI ticks.

The Evolve switch, target, amount and interval take effect immediately. Manual Generate and harmonic edits remain queued to the full phrase boundary and take priority over automatic chord evolution. A manual pending phrase is not overwritten by Evolve. Saving preserves current chords, random seed, tone settings and tone-cycle phase; opening starts stopped at the phrase beginning. This is session recall, not sample-exact restoration of effect tails or an ongoing performance timeline. Schema 1 files load into Original Warm with their existing notes/settings and chord-only evolution at their original phrase interval. Schema 2 adds the new fields and is not readable by version 0.1.x; keep older originals if you need to return to that version.

**Choose a sound without replacing the progression.** Starting Character still loads a complete preset and stops playback. Tone Patch changes sound only, retaining key, tempo, articulation, chords and locks. Synth Engine changes the architecture while retaining the other patch controls; its output crossfades over roughly 25 ms. Editing a sound control labels the patch Custom. Unsupported controls are disabled for that engine.

| Engine | Implementation | Useful controls |
| --- | --- | --- |
| Original Warm | Existing two band-limited saws plus sine, one-pole filter and original chorus/reverb path | Brightness, Motion, Attack, Release, Detune, Drive, Chorus, Space |
| Ladder | Three detuned band-limited oscillators, saturating four-stage feedback low-pass with two filter substeps per sample; polyphonic adaptation | Texture changes oscillator weight and input drive; Resonance, Filter envelope, Decay and Sustain shape pads or stabs |
| DCO | Phase-related saw, pulse-width modulation and quiet sub-oscillator; four-stage feedback filter and extra stereo chorus taps | Texture changes pulse blend and PWM depth; Chorus widens the ensemble; Detune is inactive |
| FM | Four sine operators in two modulator/carrier pairs; a slightly detuned second pair and low-pass tone shaping | Texture changes modulation index; Decay/Sustain shape the carriers and index contour; Detune, Resonance and Filter envelope are inactive |

The new paths are compact original DSP inspired by classic architectures. They are not component-level emulations, measured hardware matches, endorsed products, or clones of commercial presets. The Ladder path adapts ideas from the monophonic Minimoog to chords. The DCO path does not emulate BBD circuitry. FM is a fixed four-operator arrangement, not a complete DX7 or reface DX implementation. Nonlinear paths and FM are not fully oversampled; extreme/high-register settings can have digital coloration.

Architecture references: the [official Minimoog Model D manual](https://api.moogmusic.com/sites/default/files/2018-01/Minimoog_Model_D_Manual.pdf) describes its oscillator bank and ladder filter. Roland documents the JUNO-106's [DCO, pulse/saw/sub, envelope and chorus architecture](https://www.roland.com/uk/blog/roland-icon-series-juno-106-synthesizer/?lang=en-GB). Yamaha identifies the reface DX as a [four-operator FM instrument](https://usa.yamaha.com/products/music_production/synthesizers/reface/reface_dx.html). Those facts informed the broad topology choices; the code and listening results determine Undertone's actual sound.

**Patch bank.** Original Warm; Ladder / Amber pad; Ladder / Pocket clav; DCO / Silk ensemble; DCO / Dry comp; FM / Felt keys; FM / Glass veil; FM / Ash room; Ladder / Slow fracture. The last two also provide the rebuilt dark ambient starting characters: sustained minor harmony, long attacks/releases, slow tone evolution and more lingering space. Funk uses shorter attack/decay/filter envelopes and root-omitted syncopated chords. The existing five-hit syncopated pattern is retained; groove editing and swing are still future work.

**Verification.** The four original ambient/neo-soul six-second 48 kHz reference WAVs match the pre-change files byte for byte. Automated checks cover nonzero harmonic evolution, locks, scale/register invariants, deterministic choices, immediate controls, zero amount, tone-only audio movement, external tick boundaries, schema 1 migration, schema 2 roundtrip/validation, and distinct output from all four engines. Audio checks exercise each engine at 44.1/48/96 kHz, parameter extremes and live switches. The existing MIDI timestamp/transport suite remains in place. This evidence does not substitute for Mike's listening assessment, physical Elektron sync measurements, or an Apple silicon runtime test.

For an immediate audition, choose Neo-soul / Sunday, lock the phrase, select DCO / Silk ensemble, enable Evolve, choose Tone only and two bars, and raise Variation to about 0.6. Then try Ladder / Amber pad and FM / Felt keys against the same chords. Choose Dark ambient / Ash room for a slower composition texture. Starting Character is intentionally separate from Tone Patch.
